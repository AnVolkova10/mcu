# MCU Archive

An in-universe chronology of the Marvel multiverse: every event placed in the year it happens inside the story, not when it was released. It covers the MCU, the Fox X-Men films, the 1990s Marvel animated universe with X-Men '97, and Spider-Noir.

Live at **https://anvolkova10.github.io/mcu/**.

```bash
npm install
npm run dev        # http://localhost:5173/mcu/
npm run dev:phone  # same, reachable from a phone on the same network
npm run build      # validates the content, type-checks and builds
```
